# GlowZephyr

GlowZephyr is a cloud-native edge platform that manages event-driven stream-processing pipelines with a distributed orchestrator.

GlowZephyr is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- GlowZephyr is a cloud-native edge
- platform that manages event-driven stream-processing
- pipelines with a distributed orchestrator

## Key Features

- GlowZephyr is a cloud-native edge

- pipelines with a distributed orchestrator

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/GlowZephyr.git`
2. `cd GlowZephyr`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
